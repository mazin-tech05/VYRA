# VYRA

3D tours, honest AI photo finishing, floor plans and launch packs for New Zealand real estate agents and short-stay hosts, with virtual renovation inside the tour coming next. Deep navy and creme gold theme.

This is the showcase site. It is plain HTML, CSS and JavaScript with no build step; open `index.html` through any static web server.

The three sample homes are published 3D scans licensed under CC BY 4.0. Full credits are in the site footer.
